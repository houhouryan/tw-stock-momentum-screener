### 3.2 F02｜collection 元素的空白與型別

**Before：** `UniverseResult(included_security_ids=["   "], ...)` 成功建立，runtime 為 `('   ',)`。

**After：** 新增 private helper

```python
def _reject_blank_elements(values: tuple[str, ...], path: str) -> tuple[str, ...]:
    for index, value in enumerate(values):
        if not value.strip():
            raise ValueError(f"{path}[{index}] 不得為空字串或純空白")
    return values
```

在 `UniverseResult` 與 `SignalFrame` 的 after-validator 開頭呼叫。**不自動 strip**——`" SEC-1 "` 會原樣保留（§四 4.4 附測試）。非 str 由 `StrictStr` 擋下。

### 3.3 F03｜strict date 與 datetime

**Before：** `as_of_date="2026-08-03"`、`as_of_date=datetime(2026,8,3,0,0)`、`matured_at="2026-08-17T10:30:00Z"` 三者都被靜默轉型。

**After：** 只在三個 field declaration 加 `strict=True`：

```python
class SignalFrame: as_of_date: date = Field(strict=True)
class LabelFrame:  as_of_date: date = Field(strict=True)
                   matured_at: AwareDatetime | None = Field(default=None, strict=True)
```

**未啟用 global strict**，`LabelStatus` 等既有語意不受影響。JSON round-trip 完整保留（§四 4.5）。
