### V-2　import 會在**套件原始碼目錄**產生 `__pycache__`（具名例外）

§3.5 證明**工作目錄**無任何新增檔案，符合 §7.7 要求。但完整揭露：

**這是 CPython 對任何模組的預設行為，非本 package 的程式邏輯所致**，且不屬 DB／設定／log／網路類副作用，並已被 `.gitignore:5` 的 `__pycache__/` 排除（§3.2 已附 `git check-ignore` 證據）。

我認為稱「import 無副作用」而不提此點會構成過度宣稱，故具名列出。
