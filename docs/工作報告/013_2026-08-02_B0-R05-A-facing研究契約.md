### 3.1 五個 model 的公開欄位

| Model | 欄位（逐字） |
|---|---|
| `UniverseExclusion` | `security_id`、`rule_id`、`reason_code`、`evidence` |
| `UniverseResult` | `included_security_ids`、`exclusions`、`universe_version`、`eligibility_filter_version` |

五者的 `model_fields` 與 `model_json_schema()["properties"]` 皆經測試逐字比對（§四 4.2）。

### 3.2 關鍵 invariant

| 契約 | 實作 |
|---|---|
| included 不重複、exclusions 三元組不重複、included 與 excluded 不重疊 | `UniverseResult` 的 `model_validator(mode="after")` |
| `strength` 只能 0.0／1.0，且**拒絕 int、bool、str** | `mode="before"` 強制 `type(value) is float`，再檢查值域。見 §五 V-1 |
| `results` 與 `active_signal_ids` **完整同序**，不可得訊號仍留在 results | `SignalFrame` 的 after-validator 比對 tuple 相等 |
| pending／unavailable 三個 label 必須 null，**不得填 0** | `LabelFrame` 的 after-validator；pending 另強制 `matured_at` 為 null |
| 三個 label 只接受 int 0／1，**拒絕 bool** | `isinstance(value, bool)` 檢查置於值域比對之前 |
| `matured_at` 只接受 aware，正規化 Asia/Taipei，無 default now | `AwareDatetime` ＋ after-validator |

### 3.3 JSON、tuple 與 mutation 邊界

沿用 R04 FIX1／FIX2 已驗證的策略，但**在 `research.py` 內自行實作 private helper，未 import acquisition 的 private helper**（§8.1 明訂）：

- 建構時 `mode="before"` 遞迴重建 canonical JSON（逐層 key 排序、`type(...) is` 精確比對、拒絕密鑰與非有限數）。
- 讀取時 `_ResearchModel.__getattribute__` 對 `_json_guarded_fields` 回傳 `copy.deepcopy`。
- 序列化時 Pydantic 直接讀 `__dict__`，**不需覆寫任何 dump 方法**。
- collection 以 `_require_builtin_sequence()` 精確比對 built-in list／tuple，拒絕自訂序列型別、list／tuple 子類別與 generator。

### 3.4 A-facing 範例

