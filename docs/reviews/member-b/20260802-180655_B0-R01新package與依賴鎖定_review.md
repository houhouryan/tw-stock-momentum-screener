- 不得把 stat 的總數字標成 additions。

驗收：

- 報告中的數字可由所附命令直接重現。
- tracked 與 untracked 證據分開。

### 7.5 pyproject.toml 的品質設定

Ruff：


要求：

### 7.7 scripts/check.sh 必要行為

檔案必須：

- shebang 使用 bash。
- set -euo pipefail。
- 從任何 cwd 啟動都先定位 repo root。
- executable bit 已設定。
- 不寫檔、不自動 format、不自動 fix。
- 任一子命令失敗即以非零結束。

執行順序：

~~~bash

uv run --frozen mypy src/hotstock
uv run --frozen pytest
~~~

check.sh 內不得使用 ruff format（無 --check）、ruff check --fix 或任何會靜默改檔案的選項。
