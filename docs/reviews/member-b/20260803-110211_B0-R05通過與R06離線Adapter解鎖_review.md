## 9. FixtureAdapter 實作契約

### 9.1 固定 fixture 結構

`tests/fixtures/adapters/metadata.json` 保存固定 request／artifact／health metadata，至少包含：

- `source_id`、`dataset_id`、不含 credentials 的 `request_json`。
- 固定 `artifact_id`、`license_snapshot_id`、`source_run_id` UUID。
- 固定 aware `retrieved_at` 與 fixed aware `checked_at`。
- 固定 `http_status`、`mime_type`、`raw_uri`、`retry_count`。
- `raw_uri` 使用穩定的 fixture URI，不得嵌入開發者的絕對 home path。

`valid.json` 是原始 bytes，內容採最小 JSON object，含 `rows` array；每個 row 都是 string-key JSON object。`malformed.json` 必須是確實無法解析的固定原始 bytes，用來證明 normalize 失敗不會破壞 RawArtifact。

不要在 metadata 直接填 `content_hash`；`fetch()` 必須對實際讀到的 raw bytes 計算 lowercase SHA-256，否則 fixture 無法測出檔案內容與 metadata 漂移。

### 9.2 FixtureAdapter 行為

- constructor 明確接收 `source_id`、`dataset_id`、metadata path 與 raw path；不得搜尋目前目錄、glob 或自動挑最新檔。
- constructor 只驗證兩個 ID 為非空字串並保存明確 paths；constructor／module import 都不做 I/O，`fetch()` 才讀取指定的兩個固定檔案。
- `fetch()` 必須交叉驗證 metadata 內的 `source_id`／`dataset_id` 和 constructor attributes 完全一致；不一致即拒絕，不可覆寫其中一方。
- `fetch(request)` 拒絕 request 的 source／dataset 與 adapter 不一致。
- `fetch()` 讀 raw bytes、計算 content hash，使用 metadata 建立完整 `RawArtifact`；不得呼叫網路、寫檔或產生現在時間／隨機 UUID。
- `normalize(artifact)` 先確認 artifact 屬於同一 source／dataset，且 content hash 與 raw bytes 一致，再解析固定 JSON。
- 正常 payload 產生 `NormalizedBatch`；相同 fixture 重跑時 equality 與 JSON dump 都一致。
- malformed 或 shape 錯誤必須以 `HotstockError(ErrorCode.DATA_QUALITY, ...)` 失敗；context 只能放安全、可 JSON 序列化的定位資訊。
- `healthcheck()` 使用 metadata 的 fixed `checked_at`，不得讀系統現在時間；健康判斷只針對本地 fixture 是否可讀及 metadata 是否有效。
- 任何失敗都不得修改輸入 `FetchRequest`、先前的 `RawArtifact` 或 raw fixture。

`src/hotstock/adapters/__init__.py` 公開 export `SourceAdapter` 與 `FixtureAdapter`，只做 import／`__all__`，import 時不得讀檔、讀設定、讀現在時間或建立 adapter instance。export 測試採子集合＋不重複，不綁死永久總數。

### 9.3 不得把 fixture 變成 production shortcut

FixtureAdapter 是參考實作與測試工具，不是正式 TWSE／TPEx adapter。A-facing 文件必須清楚寫：

- 正式 Adapter 可複製 interface 與錯誤／Raw-first 流程，不能把 fixture path 當正式資料來源。
- 正式 HTTP、retry、license registry 與 persistence 由後續輪次／A 的實作處理。
- Adapter 只負責來源邊界；Signal／Scoring 不得看來源名稱或 import 具體 Adapter。

## 10. R06 測試與驗收矩陣

### 10.1 Protocol 與 import

- `FixtureAdapter` 結構上符合 `SourceAdapter`。
- 自製最小 class 只要具備兩個 attributes 與三個 methods，也能符合 Protocol；不要求繼承。
- 缺少任一 method 或 attribute 的 class 不符合 runtime Protocol。
- `hotstock.adapters` public export 包含 `SourceAdapter`、`FixtureAdapter` 且沒有重複。
- import `hotstock.adapters` 不產生檔案 I/O、網路、現在時間或環境依賴。

### 10.2 Fetch／Raw

- valid fixture 的 `RawArtifact.request` 與固定 metadata 一致。
- `content_hash == sha256(raw_bytes).hexdigest()`，不是 rows 或 dump 的 hash。
- artifact／license／run UUID、aware retrieved_at、HTTP status、MIME、URI、retry count 全部可核對。
- 同 fixture fetch 兩次得到相等、dump 相同的 RawArtifact。
- source／dataset mismatch 被拒絕。
- metadata 含未知欄位、naive datetime、secret key、錯誤 UUID 或不合法型別時被拒絕；可在 `tmp_path` 複製最小變體測試，不新增 scope 外 fixture。

### 10.3 Normalize／失敗保留

- valid fixture 產生 expected rows、row_count、dataset_id 與 artifact_id。
- 連續 normalize 兩次的 model equality、plain dump 與 JSON dump 完全相同。
- 修改呼叫端取得的 rows／dump 不污染既有 batch。
- malformed JSON 與錯誤 top-level shape 會產生 DATA_QUALITY 類錯誤。
- 在 normalize 失敗前先保存 RawArtifact snapshot；失敗後 artifact equality、hash、request metadata 與 dump 全部不變。
- artifact source／dataset／hash 和本 adapter 不一致時拒絕，不拿錯 raw 產生 batch。

### 10.4 離線與架構邊界

- adapter tests 以 monkeypatch 讓 socket connection、`requests.Session.request` 等網路入口一旦被呼叫就立即失敗；全部測試仍通過。
- `fixture.py` 不 import `requests`、`urllib`、`httpx` 或 socket。
- 架構測試以 AST 或等價的可靠方式掃描現在及未來存在的 `domain`、`research`、`signals`、`scoring` modules，禁止它們 import `hotstock.adapters.fixture` 或任何具體 Adapter implementation。
- 架構測試不得只 grep 一個目前不存在的檔名，也不得因 signals／scoring 尚未建立就永遠空跑。
- 測試完全離線，不依賴組員 A 的 branch、home path、執行日期或檔案 mtime。

### 10.5 Gate 與 package

- `uv run --frozen pytest tests/unit/adapters tests/architecture -q` 全綠；記錄實際 collected／passed，不預先綁死數量。
- `./scripts/check.sh` 六段全綠；完整測試數應大於目前 555，但新測試不得用固定全案總數作契約。
- `uv run --frozen mypy --no-incremental src/hotstock` 通過。
- `uv lock --check`、`git diff --check` 通過，`uv.lock` 無差異。
- offline wheel 只包含 production package：`hotstock/adapters/base.py`、`fixture.py`、adapters `__init__.py` 與既有 package 各一次；不得把 `tests/fixtures`、工作報告或 legacy 放進 wheel。
- build 產物只放暫存目錄並清掉；repository 不留 `dist/`／`build/`。
