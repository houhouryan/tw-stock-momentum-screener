## 6. 為什麼仍需 FIX2，而不是直接 PASS

R03 的程式碼、型別、測試與 build 現在都通過；沒有要求工程師修改任何實作。尚缺的是最後一段可稽核鏈：

```text
工作報告 008（刪除前，BLOCKED）
    ↓ 專案經理核准完整 legacy 刪除
ADR-0002＋七檔刪除＋現行文件同步
    ↓ 刪除後正常 mypy／完整 gate 全綠
工作報告 009（必須補上這一段）
    ↓ 下一次審查
R03 PASS 與 closure commit 授權
```

如果省略工作報告 009，最後一份工程端報告會永遠寫著「完整 gate 未通過、建議修改 `scripts/check.sh`」，但實際提交卻是「沒有改 mypy 命令、改採完整刪除 legacy 且 gate 已通過」。這會讓未來成員無法只靠報告還原決策。因此本次 `CHANGES REQUIRED` 是**報告一致性要求**，不是程式退件。

此事項不需要專案經理再決定：刪除方案已明確核准並完成。除非 FIX2 驗證出現新差異，工程師可以依下列固定範圍直接執行。
