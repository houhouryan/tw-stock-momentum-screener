- 同一報告的字元摘要與 checklist 數字實際不正確。

影響：

報告是工程師、審查者與專案經理唯一的非同步決策通道。摘要錯誤會讓即使原始命令正確，決策者仍取得錯誤輸入。這不是純排版問題。

修改方式：

- 工作報告 004 已凍結，禁止修改。
- 在工作報告 005 新增「報告 004 證據更正」獨立章節。
- 更正章節至少包含：
  1. 原錯誤敘述。
  2. 實際值。
  3. 取得實際值的命令。
  4. 對第一次決策的影響。
  5. 防止重犯的固定檢查。

固定防重犯規則：

1. 數字與枚舉一律先執行命令，再寫摘要。
2. 人工摘要必須與原始輸出同時出現在同一章節。
3. 明確區分「實際觀測」與「預防性建議」。
4. 送出 REPORT-COMPLETE 前，逐項比對摘要與 raw output。
5. checklist 的總數、已完成數與未完成數必須相加一致。
6. 若摘要與 raw output 不一致，報告不得加完成標記。
7. 不用「全部」「唯一」「精確」「數字正確」等斷言，除非已有可重現證據。
