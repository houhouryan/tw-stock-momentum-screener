## 4. 唯一 finding

### R04-F05｜Major｜outer rows 接受任意自訂 Sequence

目前程式：

```python
def _canonical_rows(value: object) -> tuple[JsonObject, ...]:
    if isinstance(value, str | bytes) or not isinstance(value, Sequence):
        raise ValueError(...)
    return tuple(...)
```

`Sequence` 不只代表 built-in list／tuple；自訂類別可藉由繼承或註冊 Sequence，並實作 `__getitem__` 與 `__len__`，成為此判斷接受的物件。

審查者探針：

```python
class CustomRows(Sequence[dict[str, object]]):
    def __init__(self) -> None:
        self._items = ({"a": 1},)

    def __getitem__(self, index: int) -> dict[str, object]:
        return self._items[index]

    def __len__(self) -> int:
        return len(self._items)

NormalizedBatch(
    artifact_id=UUID(int=1),
    dataset_id="d",
    rows=CustomRows(),
    row_count=1,
)
```

實際：

```text
custom_sequence_rows=BAD_ACCEPT ({'a': 1},)
```

### 4.1 為何現有 194 tests 沒抓到

- 測試已涵蓋 custom Mapping 作為 JSON object value。
- 測試已涵蓋 built-in list／tuple outer rows。
- 但沒有 custom Sequence／list subclass／tuple subclass 的 outer-container 負向案例。
- `test_rows_must_be_array_of_objects` 測的是 dict、整數 list 與字串 list，這些會因 row 不是 object 被拒絕；它沒有證明 container type 本身被拒絕。

### 4.2 影響

這個 custom Sequence 會被重新建成安全 tuple，所以目前沒有發現 secret 或 mutable-reference 污染；風險低於 F01／F02。

但它仍代表：

- constructor 接受未核准的 custom class input。
- 程式 docstring 與工作報告 011 §3.3 的「只接受 list 或 tuple」不真實。
- Adapter 實作者可能把自訂 lazy sequence 傳進 domain boundary，讓本應及早拒絕的型別被靜默 materialize。

**裁定：Major／blocking。** 原因是 R04 的目的就是凍結精確邊界；在尚未 commit、尚未解鎖 Adapter 前修正成本最低。

```python
rows_input: list[object] | tuple[object, ...]

    rows_input = cast(list[object], value)
elif type(value) is tuple:
    rows_input = cast(tuple[object, ...], value)
else:
    raise ValueError(...)
```

之後只 iterate `rows_input`，每個 row 仍交給現有 `_canonical_json_object()`。

同時：

- 從 production import 移除不再需要的 `Mapping`、`Sequence`。
- 移除檔尾 `_ = Mapping` 與其註解。
- 不得改動 `_canonical_json_value()`、public fields、`__getattribute__`、serializer、strict fields 或 datetime。
- 不新增 dependency。

### 5.3 必加測試

在測試檔可使用 `collections.abc.Sequence` 定義負向 fixture；production 不可。

至少測：

1. built-in outer list 正常建立，runtime tuple。
2. built-in outer tuple 正常建立，runtime tuple。
3. JSON dump／validate round-trip 後 runtime tuple。
4. 自訂 Sequence of dict 被拒絕。
5. list subclass of dict rows 被拒絕。
6. tuple subclass of dict rows 被拒絕。
7. generator／iterator 被拒絕。
8. custom Mapping、nested tuple、row 非 dict 的既有拒絕不退步。
9. custom Sequence 拒絕發生在 container boundary；測試不得只靠其 row 內容故意錯誤。

負向 fixture 必須真的產生合法 dict rows，才能證明拒絕原因是 outer type，而不是 row type。
